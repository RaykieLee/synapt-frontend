# 调度器前端模块

## 概述

调度器前端模块提供了对调度管道和运行记录的管理界面，参考了alerts模块的设计模式，实现了完整的页面层次结构和弹窗式操作。

## ✅ 已完成功能

### 1. 类型定义 (`/types/scheduler.ts`)
- ✅ 完整的管道、任务、触发器和运行记录类型定义
- ✅ 查询参数和响应列表类型
- ✅ CRUD操作相关的类型
- ✅ 搜索参数类型

### 2. API接口 (`/api/scheduler.ts`)
- ✅ 管道 CRUD 操作 API
- ✅ 管道任务 CRUD 操作 API  
- ✅ 管道触发器 CRUD 操作 API
- ✅ 运行记录查询和管理 API
- ✅ 统计信息 API
- ✅ 批量操作 API

### 3. 主页面架构 (`/page.tsx`)
- ✅ 完整的管道列表页面，参考alerts设计
- ✅ 集成搜索、排序、分页功能
- ✅ 支持批量启用/禁用操作
- ✅ 点击管道行进入详情页面
- ✅ **弹窗式新建管道**（取代页面跳转）

### 4. 管道详情页面 (`/[id]/page.tsx`)
- ✅ 完整的管道详情页面结构
- ✅ 显示管道基本信息卡片
- ✅ 三个标签页管理界面：
  - **任务管理** - 显示和管理管道任务
  - **触发器管理** - 管理触发器状态和执行
  - **运行日志** - 实时显示执行记录

### 5. 子组件功能
- ✅ **任务管理组件** - 显示任务列表，支持添加操作
- ✅ **触发器管理组件** - 触发器状态管理，立即执行功能
- ✅ **运行日志组件** - 自动刷新的运行记录，包含详细状态信息
- ✅ **新建管道弹窗** - 表单验证、错误处理、成功反馈

### 6. 交互功能
- ✅ 完整的数据表格（搜索、筛选、排序、分页）
- ✅ 批量操作（启用、禁用、删除）
- ✅ 行操作（查看详情、编辑、运行、删除）
- ✅ 弹窗式创建管道
- ✅ 实时状态更新和刷新

## 🎯 页面流程设计

### 主要导航流程
```
调度器管理首页
├── 管道列表 (DataTable)
│   ├── 搜索和筛选
│   ├── 批量操作
│   ├── 新建管道 (弹窗)
│   └── 行操作 → 进入详情页面
│
└── 管道详情页面 (/[id])
    ├── 基本信息卡片
    └── 标签页界面
        ├── 任务管理
        ├── 触发器管理
        └── 运行日志
```

### 弹窗操作
- **新建管道**: 从主页面工具栏触发
- **编辑管道**: 从详情页面触发（待实现）
- **运行确认**: 从行操作或详情页面触发（待实现）

## 📖 使用说明

1. **访问主页面**: `/dashboard/system/scheduler`
2. **管道管理**:
   - 点击"新建管道"打开创建弹窗
   - 使用搜索框过滤管道
   - 选择多个管道进行批量操作
3. **查看详情**: 点击管道行的"查看详情"进入详情页面
4. **管理子项**: 在详情页面的标签页中管理任务、触发器和查看日志

## 💡 设计亮点

- **弹窗式操作**: 避免页面跳转，提升用户体验
- **层次化信息**: 主列表 → 详情页面 → 专业管理界面
- **实时状态**: 运行日志自动刷新，状态实时更新
- **完整的CRUD**: 支持完整的创建、读取、更新、删除操作
