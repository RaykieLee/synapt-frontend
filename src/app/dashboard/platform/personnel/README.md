# 人员资质管理模块

## 概述

人员资质管理模块用于管理企业人员的基本信息和证书资质，支持证书有效期跟踪和过期提醒。

## 功能特性

### 人员资质管理
- ✅ 人员基本信息管理（姓名、性别、年龄、部门、职位等）
- ✅ 人员列表查询和筛选
- ✅ 人员信息的增删改查
- ✅ 支持按姓名、部门、性别等条件筛选
- ✅ 人员详情查看

### 证书管理
- ✅ 证书信息管理（证书名称、类别、级别、颁发机构等）
- ✅ 证书列表查询和筛选
- ✅ 证书信息的增删改查
- ✅ 证书有效期管理和过期提醒
- ✅ 证书文件上传和下载
- ✅ 支持按证书名称、类别、人员等条件筛选

### 统计功能
- ✅ 人员总数统计
- ✅ 证书总数统计
- ✅ 部门分布统计
- ✅ 即将过期证书提醒

## 技术架构

### 前端技术栈
- **框架**: Next.js 15 + TypeScript
- **UI组件**: shadcn/ui + Tailwind CSS
- **状态管理**: React Query (TanStack Query)
- **表单处理**: React Hook Form + Zod
- **表格组件**: TanStack Table
- **图标**: Lucide React

## 主要组件说明

### 1. 主页面 (`page.tsx`)
- 展示统计卡片（总人员数、证书总数、部门分布、即将过期证书）
- 提供Tab切换功能，在人员资质和证书管理之间切换

### 2. 人员资质管理
- **列表页面**: 支持分页、排序、搜索、筛选
- **表单对话框**: 支持新增和编辑人员信息
- **详情对话框**: 展示人员完整信息，包括关联的证书列表
- **行操作**: 查看详情、编辑、删除

### 3. 证书管理
- **列表页面**: 支持分页、排序、搜索、筛选
- **表单对话框**: 支持新增和编辑证书信息
- **详情对话框**: 展示证书完整信息，包括有效期状态
- **行操作**: 查看详情、编辑、删除、下载证书文件
- **有效期提醒**: 自动计算并显示证书过期状态

## 特色功能

### 1. 证书有效期管理
- 自动计算证书剩余有效期
- 过期证书标红显示
- 即将过期（30天内）证书橙色提醒
- 统计页面显示即将过期证书数量

### 2. 智能筛选
- 支持多条件组合筛选
- 实时搜索功能
- 筛选条件持久化

### 3. 响应式设计
- 适配不同屏幕尺寸
- 移动端友好的操作界面

## 使用说明

### 1. 人员管理
1. 在"人员资质"标签页中查看所有人员列表
2. 点击"新增人员"按钮添加新人员
3. 使用搜索框和筛选器快速查找人员
4. 点击行操作按钮进行查看、编辑、删除操作

### 2. 证书管理
1. 在"证书管理"标签页中查看所有证书列表
2. 点击"新增证书"按钮为人员添加证书
3. 关注有效期列的颜色提示，及时更新即将过期的证书
4. 使用筛选功能按人员、类别等条件查看证书

### 3. 统计查看
1. 在主页面顶部查看统计卡片
2. 重点关注"即将过期"卡片，及时处理过期证书

## 开发规范

### 1. 代码规范
- 使用TypeScript严格模式
- 遵循React Hooks最佳实践
- 组件采用函数式组件 + Hooks

### 2. 命名规范
- 组件名使用PascalCase
- 文件名使用kebab-case
- API参数使用snake_case（与后端保持一致）

### 3. 状态管理
- 使用React Query管理服务端状态
- 使用useState管理本地UI状态
- 查询键遵循层级结构：`["personnel", "qualification|certificate", "list|detail", params]`
